# Tic Tac Toe

A two-player Tic Tac Toe game built with HTML, CSS and JavaScript.


## Features
- Two players (X and O) take turns
- Winner detection for rows, columns and diagonals
- Draw detection
- Reset button to restart the game
- Dark theme with a hover effect on the boxes

## How to Run
1. Download or clone this repo
2. Open `index.html` in your browser

## Built With
- HTML
- CSS (Grid and Flexbox)
- JavaScript
